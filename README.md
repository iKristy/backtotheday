# What Day Was It

Create a super simple static and lightweight web-app that tells you what day was {date}. The page should have an input with a calendar picker that you can also type in the date manually, and the result will tell you if it was, for example, a "Monday".

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://when-was-it.lovable.app
